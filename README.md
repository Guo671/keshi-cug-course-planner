# 课石 0.3.6

由果果开发，适用于不同学校的本地排课助手。由学生确定本学期想上的课程，课石读取完整教学班时间，按具体教学周检查冲突，生成候选课表。

## 0.3.6 首次启动兼容

完整解压后双击 `Keshi.exe`。优先使用原桌面窗口；检测到互联网标记阻止窗口组件、缺少WebView2或窗口初始化失败时，自动尝试本机Edge、Chrome，再尝试默认浏览器。页面确认加载后才报告成功。浏览器模式只访问本机127.0.0.1，不上传课表，不需要额外安装Python或.NET。

- 直接使用浏览器：双击包内 `Start-in-browser.cmd`。兼容模式成功后，下次默认沿用；想重试桌面窗口，运行 `Try-desktop-window.cmd`。
- 浏览器模式会保留一个“课石 · 本机浏览器模式”控制窗口，可重新打开页面或结束课石。关闭浏览器不会结束本地服务；结束前先确认草稿已保存。
- 账号、总库、草稿、历史仍保存在 `%LOCALAPPDATA%\Keshi`。换浏览器可能需要重新登录原账号，不需要重新注册。此次升级不用恢复或删除总库。
- 初次启动请等待，服务最多等待45秒；不要连续双击。没有浏览器或页面未确认加载时，控制窗口会显示本机地址和重试方法。
- 本模式解决的是程序已经启动后的窗口依赖问题。若Windows在执行EXE之前就拦截它，本模式也无法自行运行；不会关闭SmartScreen、智能应用控制或杀毒，也不会自动解除文件来源标记。先确认下载来自本项目；需要Windows安全策略处理时请联系设备管理者。不要从陌生站点下载DLL。

支持目标为Windows 10/11 x64；发布验证使用Windows 11与当前安装的Edge、Chrome。ARM、精简系统、组织强制安全策略等环境未承诺全面兼容。证书签名仍未提供。

## 0.3.5 保存与退出保护

修复保存课程后立即退出账号可能丢失最后修改的问题。退出前等待未落盘草稿保存，失败时可取消退出或明确放弃修改。浏览器刷新/离开时对未保存草稿请求提示；强制结束进程、断电等仍不能保证落盘。旧保存响应不会把更新的修改误报为已保存。

## 0.3.4 草稿与历史管理

新增立即保存草稿、清空并删除草稿、单条删除历史和删除全部历史。删除有确认和账号隔离；删除草稿等待已发出的自动保存完成，防止旧请求将草稿写回。草稿删除会清空当前课程与偏好，保留学生信息、历史和总库；历史删除不删除草稿和总库。显示最近100条历史。

## 0.3.3 连续编辑修复

修复快速点击不同课程的修改入口时，较慢的旧响应覆盖新编辑窗口的问题。编辑详情返回后，会核对当前账号、最后一次打开请求和课程是否仍在列表，避免误改另一门课程。

## 0.3.2 模板下载修复

修复 Windows 桌面版“下载标准 Excel 模板”无反应的问题，下载时会弹出保存对话框。导入课程号或名称不一致的表格时，现在会显示具体行号，并提醒替换或删除示例行。

已使用 0.3.1 的用户不必重装即可继续工作：从 [独立 Excel 模板](https://github.com/Guo671/keshi-cug-course-planner/releases/download/v0.3.2/keshi-course-template.xlsx) 下载模板，填写后用原软件导入。每个文件一门课，同一课程所有行的课程号和名称需一致，可包含多个教学班及多个时段。此模板也随源码提供在 `release/keshi-course-template.xlsx`。

要修复软件内的下载按钮，请完整下载并解压 0.3.2，退出旧版后启动新版。已有本地账号、总库、草稿和历史继续使用，无需重新注册或重新导入。

## 排课流程

1. 填写学校（选填）、目标年份、春秋学期、学院、专业和年级。行政班号选填，用于优先推荐面向本班的教学班。
2. 添加课程：从总库按名称/课程号搜索；导入 1–20 个 XLS/XLSX；或手动填写课程。
3. 核对完整教学班。每门课可有多个备选班，每个班可有多个时段。名称必填；普通课程周次、星期和节次必填。时间未定的实践记录可设为不占时段，仅保留已知周次。教师、校区、地点选填。支持编辑、复制时段、删除时段和删除课程。
4. 设置不能上课的时间、不想上的教师、锁定/排除教学班、早晚课与集中上课偏好。
5. 点击排课。先尽量排入更多课程，再考虑重要程度和偏好。默认显示前 10 种，可继续请求更多，每次最多 100 种。课表支持全部周次概览和单周查看。

同一课程号属于同一门课程，不能重复排入。直接导入已在待排列表中的同课程号文件时，本次完整课表更新旧待排记录。A/B 等后缀班不能仅凭名称确定理论、实验关系，软件要求先在编辑窗口核对，将必须一起上的班合成完整组。

## 文件导入

- 总库：一次导入 1–5 个 ZIP，内部可以有目录，读取其中 XLS/XLSX。多个压缩包构成同一批快照。全部文件验证完成后才替换原库。
- 待排课程：一次导入 1–20 个 XLS/XLSX，每个工作簿一门课程、一个工作表，可包含多个教学班。导入失败不会写入半套数据。
- 支持已验证的学校教务系统课程课表布局，以及课石下载的标准 Excel 模板。并非任意 Excel 排版都能识别。
- 标准模板列：课程号、课程名称、教学班、教师、周次、星期、开始节次、结束节次、校区、地点、时间类型。一行一个时段，同一教学班可占多行。
- 周次支持不连续范围和单双周，节次为 1–20，教学周为 1–64。
- ZIP 中非 Excel 文件明确报告为未读取，不进行 PDF 识别。损坏、越界、加密等异常导致整批导入失败，原库保留。
- 单个上传文件不超过 32 MB，每批合计不超过 100 MB；解压另有资源限制。学校若改变导出排版，可能仍需更新解析器，日常课程内容变化只需更换数据。

培养方案入口、接口、匹配逻辑、内置培养方案数据和相关提取工具已经移除。运行包不包含培养方案资料或 PDF 解析功能。旧版草稿中实际已选的课程会迁移成普通待排列表，旧历史记录保留。

## 实践类记录的时间规则

实习、课程设计等没有具体星期和节次的记录，按不占时段处理，不与任何课程或其他实践冲突，不计请假。课程仍显示在方案明细中，保留原始周次。已有精确时段的课程继续严格检查冲突。标准模板可在“时间类型”填“不占时段”，手动编辑也可选择此类型。

## 无完整无冲突方案时

普通课表继续严格检查冲突，另行给出调整建议。一门课程在某周某天的一次连续上课时段算一次请假；一次请假可以解决多个重叠，不重复计数。先寻找保留全部课程的最少请假方案；超过 10 次时，寻找请假不超过 10 次的最少删课方案。超时结果会标明未证明最优。

调整建议列出课程、周次、星期、节次及采用的教学班。建议不代表已经获得请假许可，也不会自动删除课程。教学资格、课程性质、先修要求、实时余量和最终选课，以学校教务系统及相应要求为准。

## 内置课程数据

默认内置总库属于中国地质大学（武汉）2026年秋季。其他学校应导入自己的课程，不能将默认总库当作本校数据。三个ZIP逐表读取结果：

| 内容 | 数量 |
|---|---:|
| 表格文件 / 独立课程 | 1,212 |
| 教学班记录 | 3,318 |
| 全部时段完整的教学班 | 3,070 |
| 含不占时段实践记录的教学班 | 248 |
| 上述248个中同时有精确课时的混合班 | 40 |
| 精确上课时段记录 | 9,405 |
| 非精确时段记录 | 315 |

以上计数区分精确时段与非占位实践；带组成关系疑问的教学班还必须额外确认。已选人数不等于容量，无法推算剩余名额。

## 源码启动

需要 Python 3.12。创建虚拟环境后执行：

```powershell
py -3.12 -m venv .venv
.\scripts\setup.ps1
.\scripts\start.ps1
```

浏览器访问 `http://127.0.0.1:8765`。初始化不再自动寻找旧课表覆盖数据，请在软件界面导入课程总库。公开源码不包含个人数据库或原始课程文件。

源码使用 MIT 许可证，作者为果果（GitHub：Guo671）。课程资料的使用范围见 [数据声明](DATA_NOTICE.md)。
