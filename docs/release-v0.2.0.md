# 课石 v0.2.0

面向中国地质大学（武汉）学生的 2026 年秋季本地智能排课助手首个公开版本。

## 下载与运行

1. 下载 `课石-v0.2.0-win64.zip` 和 `SHA256SUMS.txt`。
2. 核对 SHA-256 后完整解压到普通文件夹。
3. 在 Windows 10/11 64 位系统中双击 `Keshi.exe`。

不要直接在压缩软件中运行，也不要只复制单个 exe。系统需要 Microsoft Edge WebView2 Runtime，Windows 10/11 通常已经预装。

## 主要功能

- 按课程名称或课程号选择课程；支持手动、培养方案和混合三种输入方式。
- 自动组合具体教学班并按教学周检查冲突。
- 支持不可排课时段、教师排除、教学班锁定/排除、早晚课和集中上课日等偏好。
- 可行方案不超过 10 种时全部列出；更多时按推荐顺序显示前 10 种。
- 明确解释未排入原因、资格风险、数据风险和仍需在教务系统完成的事项。
- 所有账号、偏好、草稿与历史方案仅保存在本机；软件不会获取统一身份认证密码，也不会代替学生提交选课。

## 数据与适用范围

内置课程数据来源于中国地质大学（武汉）学校教务系统，是用于 2026 年秋季排课辅助的离线快照。容量、开放状态、限制、教师、时间和地点可能变化，最终必须以学校教务系统为准。课程数据与培养方案资料不属于 MIT 源代码许可证的授权范围，详见压缩包内的 `DATA_NOTICE.md`。

本项目是独立的非官方辅助工具，不代表中国地质大学（武汉），也未获得学校认可或背书。

## 完整性校验

以同一发布页提供的 `SHA256SUMS.txt` 为准。发布流程已运行后端测试、前端测试、静态检查、类型检查、培养方案校验和冻结程序 smoke test，并确认发布数据库不含本机账号、会话、学生档案、偏好或历史方案。
