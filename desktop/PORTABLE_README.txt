课石 · 地大排课助手 0.2.0（Windows 便携版）
=================================================

启动
----
1. 将压缩包完整解压到普通文件夹；不要直接在压缩软件里运行，也不要只复制 exe。
2. 双击 Keshi.exe。
3. 首次启动会把内置课程总库复制到当前 Windows 用户的数据目录，可能需要数秒。

系统要求
--------
- Windows 10/11 64 位。
- Microsoft Edge WebView2 Runtime。Windows 10/11 通常已预装；若程序明确提示缺少，
  请从微软官方页面安装 Evergreen Runtime 后重试。

数据与隐私
----------
- 用户数据库：%LOCALAPPDATA%\Keshi\data\planner.db
- 日志：%LOCALAPPDATA%\Keshi\logs\desktop.log
- 浏览器本地状态：%LOCALAPPDATA%\Keshi\webview
- 升级便携包不会覆盖上述用户数据。备份时请退出课石，再复制整个 Keshi 数据目录。
- 课石不需要、不会保存中国地质大学统一身份认证密码，也不会代替学生向教务系统
  提交选课；最终选课结果仍需本人核对并在官方系统操作。

端口与单实例
------------
课石只在本机 127.0.0.1 启动服务，优先使用固定端口 18765，以保持浏览器本地设置。
如果该端口被别的软件占用，会自动使用临时端口。本机同时只允许运行一个课石实例。

诊断
----
在 PowerShell 中进入本文件夹后可运行：
  .\Keshi.exe --version
  .\Keshi.exe --smoke-test

若无法启动，请先完整重新解压，再把上述日志连同错误提示一并反馈。课程与培养方案
均有适用范围和来源日期，请在正式选课前以学校、学院和教务系统最新通知为准。
