课石使用说明

由果果开发 · 适用于不同学校的本地排课工具

本说明随软件保存在电脑中，断网也能打开。课石帮助你在已经确定要修读的课程之间选择教学班、核对时间并生成候选课表。正式选课仍须在学校教务系统完成。

一、第一次使用

  1. 将便携包完整解压，双击 Keshi.exe。不要只复制 exe；它需要旁边的运行文件。
  2. 创建课石本地账号，或登录已经在这台电脑注册的账号。
  3. 填写自己的学校（选填）、目标年份、春季或秋季、学院、专业和入学年级。行政班号选填，例如 072242，用于优先推荐面向本班的教学班。
  4. 从总库搜索课程，或导入 Excel 课表，也可以直接自行填写课程。
  5. 检查每一门课的所有备选教学班与时段。设置不能上课的时间、不想上的教师及其他偏好。
  6. 点击“开始智能排课”，查看已排入、未排入课程和提示。回到教务系统核对并实际选课。
不需要使用培养方案导入，也不需要填写开发者接口令牌。课石不支持 PDF 课表导入。

二、账号与断网使用

账号保存在本机，不是互联网账号。默认在同一 Windows 用户下使用同一份课石数据库；不同电脑、不同 Windows 用户或指定的不同数据目录之间不会自动同步。

  • 同一台电脑可以注册多个课石账号，退出后登录另一个本地账号。只在别的电脑注册过的账号，不能自动在这里登录。
  • 同一份数据库不允许重复用户名。用户名会去除首尾空格、统一大小写和全角形式，因此 Alice 与 alice 视为同名；姓名相同的同学可添加班级或数字区分。
  • 不同用户名可以使用相同密码，不会覆盖或串号。密码以带随机盐的散列保存，不以明文保存。当前版本没有邮箱找回密码功能。
  • 个人档案、待排草稿和历史方案按账号分开。课程总库是本机共享资料：任一账号删除或替换总库，会影响这份数据库中的其他账号可搜索的课程，但不会删除其他人的个人记录。
  • 总库导入完成后，登录、搜索、手动编辑、生成方案、查看历史和本说明均可断网使用。新课表的获取、学校教务系统选课可能需要网络。

三、课程总库与待排课程的区别

本版本内置总库属于中国地质大学（武汉）2026年秋季，不是其他学校的课程资料。其他学校用户请导入自己的总库或标准模板，也可自行填写课程；不必使用内置总库。

总库是供搜索的大范围课程目录；待排课程是你本学期实际想上的课。导入全校一千多门课程不会把它们全部加入个人排课。

打开“课程总库管理”，一次选择同一学期的 1—5 个 ZIP。ZIP 内可有子文件夹，读取其中的 XLS／XLSX。每个工作簿应是一门课程的完整课表。检查完成后，整批文件合并为一个新总库并替换旧库。

  • “删除课程总库”仅删除共享课程目录，不删除账号、个人草稿或历史。
  • “恢复本版本内置总库”会以当前客户端自带的快照替换共享总库。升级客户端不会擅自覆盖你自行导入的数据，旧用户可手动执行恢复。
  • “清空待排课程”只清空当前账号的待排列表，不删除总库。
  • 总库更换后，旧课程的教学班编号或时间可能失效；请重新核对并生成方案。历史结果保留当时的信息，不代表新库仍然相同。

四、从 Excel 导入课程

已下载自己想上的课时，使用“导入课程课表”，选择 1—20 个 XLS／XLSX，再点击“导入到待排课程”。每个文件一门课程、一个工作表，可包含该课程的多个教学班。

支持已经验证的学校导出课表布局，以及软件内下载的“标准 Excel 模板”。文件扩展名相同不代表排版相同，任意制作的表格不一定能识别。

模板列填写方式
课程名称必填。同一工作簿使用同一课程名称。
课程号选填，建议填写学校课程号并设置为文本。相同课程号属于同一门课。
教学班例如 0001、0002；同班多时段填写多行。不同班是备选。
教师选填，多位教师以逗号或顿号分隔。
周次普通精确课程必填；不占时段的实践记录可只填写已知周次。例如 1-5,7-8、1-16周(单)。这是教学周，不是月份或日期。
星期普通精确课程必填，不占时段记录可空，填写 1—7 或周一至周日。
开始节次、结束节次普通精确课程填整数 1—20，结束不得早于开始。第5—6节填 5、6；不占时段记录可空。
校区、地点选填，如南望山校区、东教楼C0108。
时间类型普通课程留空或填“精确时间”；时间未定的实习、实践、课程设计填“不占时段”。同一个班可混合填写两种记录。

模板示例数据需要替换。同一教学班每一行表示都要参加的时段。普通精确课程不能缺少周次、星期或节次；“不占时段”记录可保留已知周次，不需要编造星期或节次。教师或地点为空不妨碍排课。

再次直接导入与待排列表同课程号的文件时，新完整课表会更新旧待排记录。请核对是否为同学期最新版；不要把仅有一部分教学班的文件误当完整替换文件。

损坏文件、无法识别的时间、多个工作表等问题会给出错误。总库导入失败时原库保留。ZIP 中非 Excel 文件会列为未读取，不能将“读取部分文件”当作读取了全部资料。

五、手动添加、修改和组合教学班

点击“自行填写课程”。课程名称必填。普通课程需要完整上课时间；时间未定的实习、课程设计等可勾选“不参与冲突”，仅保留周次。课程号、教师、校区、地点选填。填写完一个时段，可继续添加其他时段，也可复制后修改周次或星期。

例如同一教学班有两个时段：第1—5、7—8周，周二第5—6节；第1—3、6—8周，周五第3—4节。应在同一个教学班下填写两条，排课时会同时检查两条记录。

  • “添加备选教学班”：添加另一种完整上课安排。排课器最多从这门课的备选班中选择一个。
  • “复制时段”：复制当前填写内容，再修改不同部分；注意不要留下重复或相互冲突的记录。
  • “删除这个时段”或“删除这个教学班”：删除错误信息；每个保留的教学班至少需要一个时段。
  • 待排列表中的“修改课程名称、教师和时间”：修改个人待排副本，不直接改动共享总库。

遇到 0001A、0001B 等后缀班

同课号只说明属于同一门课程，不能确定这些班是互相替代，还是必须一起上的理论与实验组成。软件会要求核对。把必须一起参加的班并入同一组，保证每个保留组都是完整的备选，再勾选确认并保存。

如果理论班可以搭配不同实验班，需要分别准备“理论＋实验A”“理论＋实验B”两个完整备选组，而不能只保留独立理论班和独立实验班。无法确认时，先查教务系统或询问任课教师。

六、设置排课偏好

默认使用通用排课模式，不把某一学校的选课阶段或资格规则当作所有学校的规则。学校字段用于标识自己的学校，不会自动下载对应课程；请自行准备课程资料。

设置含义
硬约束绝不违反。例如不能上课的时间、绝不选择某教师，可能导致部分课程排不进去。
软偏好尽量满足，在无法兼得时允许折中；不是保证。
必须排入要求这门课进入普通候选课表；与其他必须课程或锁定教学班冲突时可能没有可行方案。
重要程度首先争取排入更多课程；课程数量相同时再考虑重要程度和其他偏好。
锁定教学班必须使用指定班。解除锁定后才能自动换其他班。
排除教学班不使用指定班；不要把同一门课的全部候选都排除。
不排早课／晚课软偏好。早课按第1—2节，晚课按第9节以后处理。
行政班号用于优先匹配推荐班，不能证明你一定有跨班选课资格。

七、阅读排课结果

默认最多返回10种方案，可继续请求更多，单次最多100种。软件说明是否已经列完、是否受到时限影响；“尚未证明最优”不代表结果必然有冲突，而是未能确认它是全局最佳。

先看已排入和未排入课程，再看选择的教学班、教师、地点及逐课程解释。全部周次概览可能在同一星期同一节显示不同周上的课，这不一定冲突；切换“第几周”可以查看具体一周。

实习、课程设计等只有周次而没有具体星期和节次的记录，统一按不占用课表时段处理。它们保留在已选课程明细中，不与任何课程或实践记录产生时间冲突，也不计请假次数；教师排除、教学班选择等非时间规则仍有效。同一教学班可能同时包含两种记录：有明确星期和节次的部分继续检查冲突，缺时段的实践部分不占位。内置库248个含实践记录的班中，有40个属于这种混合情况。这个规则是软件的排课约定，不是把未知时间猜成具体时间。软件也不能根据“已选人数”推算剩余名额。课石目前不自动计算跨校区通勤时间，连续课程请自行核对地点和交通。

修改课程、时间或偏好后应重新排课。正在求解时若又修改了输入，旧结果不能作为修改后的结果使用。

八、请假与删课建议

普通课表仍严格检查时间冲突。无法同时安排全部课程时，另行提供调整建议，不会偷偷把冲突当作已经解决。

  • 某门课在某周某天的一次连续上课时段计1次请假；同一冲突持续5周计5次。
  • 一次请假同时解决多个重叠只计一次；两门不同课程分别请假计两次。
  • 优先寻找保留全部课程的最少请假方案。超过10次时，寻找请假不超过10次情况下需要删除的最少课程。
  • 建议会列出课程、周次、星期、节次和采用的教学班。超时或规模过大时可能无法给出已证明最少的建议，软件会说明。
请假建议不是学校批准，不会自动删课，也不会替你完成选课。某些课程有出勤、实验或考核要求，须先向学校或任课教师核实。

九、保存、升级和备份

课程和偏好编辑后会自动保存，请看“草稿已自动保存”提示。课程编辑窗口需先点击“保存课程”；尚未提交的弹窗内容不算已保存草稿。

默认数据目录是 %LOCALAPPDATA%\Keshi，日志在其中的 logs\desktop.log。备份前退出课石，再复制整个数据文件夹。账号不会随便携包自动搬到另一台电脑；需要完整迁移自己的数据文件夹，并避免覆盖目标电脑其他人的数据。

升级客户端通常不会覆盖原有账号和总库。请完整解压新版，再按需要恢复新版本内置库或自行导入新学期课程。历史结果记录当时的安排，不应拿旧学期结果直接选新学期课程。

十、常见问题与错误处理

看到“Available authorizations”“HTTPBearer”怎么办？

这是地址以 /api/docs 结尾的开发者接口文档（Swagger），不是普通用户界面。Value 字段用于课石登录生成的访问令牌，不是密码。普通用户关闭这个页面，回到课石窗口操作即可。

最多能注册多少账号，能自行注销吗？

当前没有人为设定注册账号数量上限，实际能力受本机资源和操作规模影响。压力测试中的25账号验证不代表最大容量。当前没有自助注销或邮箱找回入口；“退出”只结束登录，不删除账号。

为什么同名账号不能注册？

同一份本地数据库已有这个用户名时会拒绝重复注册。用另一个用户名，或登录原账号。不同密码不能把一个同名账号变成两个账号。

提示“正在处理其他任务”怎么办？

为避免重复点击或并发导入占满电脑，软件限制昂贵任务同时执行的数量。等待当前任务完成后再试，不要反复点击。

没有结果，是不是课程一定排不开？

先区分“已证明无解”和“时限内未找到结果”。检查时间输入、全部候选被排除、必须课程、锁定班、未知时间和教师限制。规模过大时先减少不需要的教学班或分批核对。

导入后少了课程怎么办？

查看导入计数和未读取文件说明。表格文件数、课程数和教学班数不是同一个概念；同课号可能合并。失败文件应修正或使用标准模板补录，不要凭“导入成功”猜测全部资料都已正确识别。

如何报告问题？

记录软件版本、操作步骤、错误原文、课程号与教学班号。可提供脱敏后的最小课表文件，说明期望结果和实际结果。不要发送密码或完整个人数据库。

本说明针对课石 0.3.1。软件是排课辅助工具，测试通过不代表所有未来文件和所有操作组合都已穷尽。
