# 课石0.3.6首次启动兼容修复与发布验证

日期：2026-09-22。基础版本0.3.5。修复范围是已出现的启动依赖故障、检测错误和发布验证缺口，并回归近期交互问题；不承诺所有硬件或Windows安全策略均兼容。

## 已实现
- 缺WebView2、关键窗口DLL存在Internet ZoneId 3/4、桌面初始化抛错或超时：保留已启动的本地服务，尝试Edge、Chrome，最后默认浏览器。
- 不自动解除文件锁定，不关闭杀毒、SmartScreen或智能应用控制，不收集身份证明。EXE执行前的系统阻止仍需用户或设备管理者处理。
- 浏览器通过短期随机令牌和精确Origin确认应用初始化；只加载HTML而核心脚本失败不会算成功。端点仅由桌面本机服务启用。
- 原生控制窗口不依赖.NET；可以重新打开页面、取消结束或确认结束服务。确认结束后监听端口释放。浏览器模式成功后沿用，支持Start-in-browser.cmd及Try-desktop-window.cmd入口。
- 修正WebView2官方注册表标识，避免把空安装目录当作有效运行时。服务冷启动等待从20秒改为45秒。窗口初始化有25秒确认时限。
- 旧数据目录保留；不同浏览器可能需重新登录同一本地账号。未修改排课算法、账号数据格式或总库内容。

## 新鲜验证证据
- 完整Python测试151项通过，JavaScript函数测试17项通过；ruff（desktop及backend/app）、mypy（backend/app）通过。
- 源码真实桌面窗口、真实Edge、真实Chrome均加载成功。
- 从最终ZIP重新解压到带中文、空格、感叹号的临时目录：原生、Edge、Chrome均通过frozen=true界面检查。
- 给解压包Python.Runtime.dll加ZoneId=3：强制原生检查复现Failed to resolve Python.Runtime.Loader.Initialize；auto检查成功转Edge，标记仍保留、DLL内容未修改。
- 移除必要前端文件：明确报告程序文件不完整，并以错误退出，不误报成功。
- 原生控制窗口和完整本机服务集成检查：重开页面、取消结束保留服务、确认结束释放服务通过。使用隔离临时数据和测试浏览器配置，不关闭用户已有浏览器。
- 真实WebView2模板下载字节一致；草稿删除/失败重试/不复活、保存后立即退出、课程编辑乱序、错误输入等正常数据量浏览器流程通过。
- 两项独立代码审查发现（前端初始化假阳性、正常原生白屏不回退）均先补失败测试后修复，复核通过。
- PDF使用WPS导出，8页，正文有文字层；DOCX正文宋体小四、黑体标题，配图已遮盖教师姓名。

## 明确边界
验证环境为本机Windows 11 x64和当前Edge/Chrome；Windows 10 x64为支持目标，未在本轮逐台实机测试。组织强制策略、ARM/精简系统、EXE运行前拦截不在自动绕过范围。关闭服务前应保存草稿，强制关进程/断电不保证未保存内容。本轮未重复大规模压力测试。
