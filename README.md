# 课石 · 中国地质大学（武汉）2026 秋季智能排课助手

这是一个本地运行的 Web 软件，用来把学生想修的课程自动组合为多个可执行的教学班课表。它按具体教学周检查冲突，支持不可排课时间、教师排除、行政班推荐课表、锁定/排除教学班、早晚课偏好、课程集中到更少上课日等设置，并解释每门课程为何被排入或未排入。草稿会按本地账号自动保存，历史方案可重新打开；课程总库变化后会提示重新求解。

软件**不会登录教务系统、不会索取统一认证密码、不会替学生提交选课**。容量、先修要求、选课限制和最终开放状态必须回到学校教务系统核对。

## 快速开始

### Windows 便携版（推荐）

从发布页下载 `keshi-v0.2.0-win64.zip` 和 `SHA256SUMS.txt`，核对 SHA-256 后把压缩包**完整解压**到普通文件夹；不要在压缩软件中直接运行，也不要只复制 exe。Windows 10/11 64 位用户双击 `Keshi.exe` 即可，无需安装 Python。系统还需要 Microsoft Edge WebView2 Runtime，Windows 10/11 通常已经预装；若课石明确提示缺少，请安装微软官方 Evergreen Runtime 后重试。

首次启动会把内置课程总库复制到 `%LOCALAPPDATA%\Keshi\data\planner.db`。账号、草稿、偏好和历史方案都保存在这里，升级或更换便携包不会覆盖。备份时先退出课石，再复制整个 `%LOCALAPPDATA%\Keshi` 文件夹；日志位于其中的 `logs\desktop.log`。课石仅在本机回环地址启动服务，不对局域网开放。

### 从源码运行

系统要求：Windows、Python 3.12。公开源码仓库不会包含本机 `.venv`、用户数据库、原始课表或构建缓存。已经自行创建环境并导入课程数据库时，可运行：

```powershell
.\scripts\start.ps1
```

然后打开 `http://127.0.0.1:8765`。

需要从头初始化时：

```powershell
py -3.12 -m venv .venv
.\scripts\setup.ps1
.\scripts\start.ps1
```

`setup.ps1` 会安装依赖，并从项目父目录读取你有权使用的 `课程课表 (1).zip` 或 `课程课表.zip`，再生成本地 SQLite 数据库。原始课表不随源码仓库分发。若同时提供项目开发时使用的旧版导出目录，导入器会按既定合并策略处理；重复执行是幂等的，账号和历史方案保留，课程目录表在一个事务中刷新。

## 三种课程输入方式

1. **手动输入**：按课程名称或课程号搜索，适用于所有学院、专业和年级。
2. **培养方案**：仅当学院官网的方案正文可直接取得、已结构化并逐页复核时启用。纯模式自动排入可安全匹配的必修课；未匹配必修、风险教学班和方向组不会被擅自选择，也不会静默消失，而会作为结果中的常驻待办要求改用混合方式处理。
3. **混合方式**：先列出培养方案中本学期课程，再由学生逐门增删、选择方向课和选修候选，最后一起排课。

学生必须明确填写学院、专业、精确入学年级、培养方案变体，以及是否属于合作/联合培养；一旦同时填写专业名称和代码，二者必须指向同一专业。建议再填写行政班号（例如 `072242`），软件会优先推荐面向本班的教学班；跨班仍可作为备选，但会持续警告核对资格。2026 秋的名义学期默认映射为 2026 级第 1 学期、2025 级第 3 学期、2024 级第 5 学期、2023 级第 7 学期，但必须由用户确认；转专业、休学、留级或提前修读时应填写实际学期。

## 数据合并策略 A

- 同一课程、教学班和班级组成出现多个版本时，最新版胜出。
- 所有旧版本仍保存在 `provenance` 中，可追溯到快照、原文件、SHA-256、工作表单元格和原始文本。
- 旧版独有教学班保留，但标记 `needs_confirmation=true`，默认不参与排课。
- 只有学生逐门显式允许后，时间完整的旧版教学班才可成为候选；风险标记不会消失。
- 集中实践只有周次而没有星期/节次时，默认不参与排课。学生单独确认后可以列入方案，但软件仍明确提示“未证明无冲突”。
- 路径穿越、绝对路径、符号链接、加密 ZIP 条目和异常压缩比会被拒绝；含 Windows 非法字符的文件名只生成安全映射，不直接解压覆盖文件。

## 已实现的约束与优化

- 按第 1–21 周、单双周、星期和节次精确检查冲突；支持周末补课。
- 不可排课时间：硬约束或软偏好，可指定教学周。
- 不想上的教师：硬排除或软偏好。
- 推荐课表班级组成：行政班匹配是高优先级软偏好；必要时允许跨班，但不隐藏资格风险。
- 必须排入、课程优先级、锁定或排除具体教学班。
- 尽量不排早课、尽量不排晚课、在课程覆盖相同时减少上课日。
- 预选、确认、补退选、重修四个阶段的解释；重修阶段强制确认“不及格或缓考”资格。
- 先最大化排入课程，再最小化偏好与数据风险代价；可靠精确时段优先于已确认的未知时段、旧快照或低置信记录。可行排课方式不超过 10 种时全部列出，超过 10 种时按推荐顺序返回前 10 种，并明确标注结果是否已列完。
- OR-Tools CP-SAT 求解；缺少 OR-Tools 时使用确定性 branch-and-bound 回退。
- 求解结果由独立验证器复核，不接受含冲突、重复选班或违反硬约束的结果。
- 结构化淘汰原因、不可行诊断、逐课程解释和风险警告。

## 选课规则边界

软件依据项目中的 2026 秋选课手册、学校 2026 秋选课通知和课程学习管理办法实现保守规则。当前日期 2026-08-23，界面默认建议“确认阶段”，但要求用户确认。

- 预选可超容量提交，并非先到先得；筛选后仍可能被移除。
- 确认、补退选和重修阶段通常先到先得，但本地课程总库没有可靠容量字段。
- 重修仅适用于不及格或缓考课程。
- 学校规则允许重修冲突后另行申请免听，但思政、军事、体育、实验、课程设计和实习等课程存在限制。本软件不会静默放开冲突。
- 实践课程即使暂无精确时段也不能忘选；软件将其作为“周次已知、时段风险未消除”处理。
- 2024 级本科生须选择“社会调查”；若课程总库未匹配到可排教学班，结果仍会保留这项教务系统待办。
- 补退选结束后一般不再有统一调整机会，最终必须核对理论、实践、线上和线下所有组成部分。

详见 [选课规则映射](docs/selection-rules.md)。

## 构建 Windows 便携包

在 64 位 Windows 和 Python 3.12 项目环境中运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-desktop.ps1
```

脚本会安装固定的桌面构建依赖、生成多尺寸图标、制作课程库种子、运行测试、构建 PyInstaller one-folder、执行冻结程序 smoke test，并生成 `release\keshi-v0.2.0-win64.zip` 与 UTF-8 `release\SHA256SUMS.txt`。种子制作有严格隐私门禁：若 `var\planner.db` 的账号、会话、学生档案、偏好或历史方案表含有任何记录，构建会拒绝继续，绝不会把本地用户数据打进发布包。`-SkipTests -SkipInstall` 只适用于当前环境已完成相应步骤的重复构建。

## 明确限制

- 不自动抢课、选课或绕过学校登录。
- 不知道实时容量、先修审核、学籍限制和临时停开状态。
- B/C/D 级培养方案不会自动推断。
- 旧版独有课程的存在不代表当前仍开设，最新版缺失也不能单独证明已取消。
- 方向、课程组和个体培养进度必须由学生确认。
- 生成课表是决策辅助，不是学校选课结果。
