# 使用指南

## 1. 启动与登录

### 1.1 Windows 便携版

下载 `课石-v0.2.0-win64.zip` 后先对照 `SHA256SUMS.txt` 核验文件，再完整解压并双击 `Keshi.exe`。不要在压缩软件预览窗口中运行，也不要把 exe 单独移出文件夹。首次启动复制内置课程库可能需要数秒；重复双击时课石会提示已有实例，而不会启动两个本地服务。

便携版需要 Windows 10/11 64 位和 Microsoft Edge WebView2 Runtime。若缺少运行库，课石会显示明确错误；安装微软官方 Evergreen Runtime 后重新启动即可。

首次使用创建的账号是本机账号，不是学校统一认证账号。账号、学生档案、草稿、偏好和历史方案位于 `%LOCALAPPDATA%\Keshi\data\planner.db`，浏览器本地状态位于 `%LOCALAPPDATA%\Keshi\webview`，日志位于 `%LOCALAPPDATA%\Keshi\logs\desktop.log`。升级时只需退出课石并替换便携程序文件；程序不会覆盖用户数据库。备份或迁移前先退出课石，再复制整个 `%LOCALAPPDATA%\Keshi` 文件夹。

### 1.2 从源码运行

在项目目录运行 `scripts/start.ps1`，浏览器打开 `http://127.0.0.1:8765`。源码模式同样使用本地账号，不需要学校统一认证密码。

## 2. 填写学生身份

学院、专业和入学年级必须填写。培养方案班型、专业代码、合作项目必须按本人情况核对；专业名称与代码矛盾时，软件会禁用培养方案输入，避免套用其他专业方案。

行政班号建议填写，例如 `072242`。软件优先选择课程表中面向该班的教学班；如果硬约束迫使结果跨班，会显示班级组成并提示回教务系统核对资格。

软件按年级推算 2026 秋所处学期，但转专业、休学、留级或提前修读学生必须填写实际培养方案学期并勾选确认。

## 3. 选择课程输入方式

- **手动输入**：按课程号或名称搜索并添加课程，所有学生都可用。
- **培养方案**：只对已取得官方正文、完成结构化和复核的方案开放。软件只自动提交当前学期中可安全匹配的必修课；未匹配、方向组和风险课会作为结果中的待办保留。
- **混合方式**：先查看方案课程，再选择方向、增删课程和手动补充。删掉的已匹配必修与仍未匹配的必修都会在结果中持续提醒。

官网没有找到可核验完整方案时，页面会明确显示“仅支持手动输入”，不会借用相近专业、其他学院或不适用年级的方案。

## 4. 核对教学班和数据风险

展开已添加课程的“查看并指定教学班”，可锁定一个教学班或排除多个教学班。每个班显示教师、时间、地点、班级组成和数据状态。

风险需要分开确认：

- **旧版独有**：最新版课程总库没有该班；显式允许后仍要回教务系统确认是否开设。
- **当前数据低置信度**：原表解析信息不足；显式允许后仍要对照原始课表。
- **具体时段未知**：只有周次或待通知；单独允许后也不能证明无时间冲突。

这些确认只允许教学班进入候选，不会移除结果中的风险警告。

## 5. 设置约束并生成

可添加不可排课时间和不想上的教师，并选择硬约束或软偏好；还可设置早课、晚课、紧凑上课日、必须排入、课程优先级、选课阶段和重修资格确认。

生成结果先最大化排入课程，再比较偏好与数据风险代价；在其他条件相同时，可靠的精确时段教学班会排在已确认的未知时段、旧快照或低置信记录之前。可行排课方式不超过 10 种时会全部列出；超过 10 种时只显示推荐顺序最靠前的 10 种。结果区会明确说明“已全部列出”“还有更多”或“受求解时限影响、尚不能确认”。桌面课表与移动日程均显示课程、教学班、教师、校区/教室、周次；下方解释每门课的安排或未排原因。

## 6. 草稿、历史与最终核对

课程、教学班和约束修改后会自动保存到当前本地账号。重新登录会恢复草稿；“草稿与最近方案”可打开历史结果。课程总库更新后，旧草稿和历史会显示过期，需重新生成。

本软件不登录或操作学校教务系统。最终选课前必须回教务系统核对容量、先修、开放对象、停开状态及理论/实验/实践全部组成。2024 级还必须核对“社会调查”选课要求。

## 7. 维护者构建便携版

在 64 位 Windows、Python 3.12 项目环境运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-desktop.ps1
```

成功后使用 `release\课石-v0.2.0-win64.zip` 和 `release\SHA256SUMS.txt`。脚本会实际运行冻结后的 `Keshi.exe --version` 与 `Keshi.exe --smoke-test`，并核对本地 API 健康状态。若项目数据库中存在任何账号、会话、学生档案、偏好或历史方案，隐私门禁会让构建失败；应改用不含用户记录的官方课程库，不能发布日常使用中的数据库。
