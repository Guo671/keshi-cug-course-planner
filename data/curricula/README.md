# 中国地质大学（武汉）培养方案数据

本目录是面向 **2026 年秋季（2026-2027-1）** 排课软件的官方来源快照，检索日期为 **2026-08-23**。它覆盖学校 2026 年本科招生专业目录中的 76 个专业、20 个学籍归属学院，以及检索中确认的 3 个特殊培养单位。未找到当前完整培养方案的专业被明确标为手动输入，绝不使用相近专业、旧版方案或特殊班方案猜填。

## 文件

- `source_registry.json`：97 条专业/班型来源记录，含官网落地页、直接附件（若有）、发布日期、适用年级、访问方式、证据和限制。
- `plans/measurement-control-2023.json`：测控技术与仪器 2023 版，68 条课程记录。
- `plans/automation-2023.json`：自动化 2023 版，79 条课程记录。
- `schema/*.schema.json`：JSON Schema Draft 2020-12。
- `validate.py`：Schema 与跨字段语义校验。

官方 PDF 仅用于临时解析和逐页核对，**没有提交到项目**。两份 A 类计划文件内保存了下载 URL、字节数、页数和 SHA-256，可用于以后重新下载时做同一性检查。

## A—D 访问级别与软件启用规则

| 级别 | `access_mode` | 含义 | 软件行为 |
|---|---|---|---|
| A | `direct` | 官网附件可直接下载，且已逐页解析、复核 | 可启用“培养方案导入”和“培养方案 + 手工编辑”的混合模式；导入前仍须确认学院、专业、年级、班型 |
| B | `captcha/upload_required` | 官网落地页和附件存在，但下载需要验证码 | 展示官方证据并提示用户/管理员上传原文件；上传、解析、Schema 校验和人工确认均完成前，仅允许手动输入 |
| C | `auth_required` | 页面存在但需要学校统一身份认证 | 不收集或代填凭据；由有权限用户导出并上传原文件，在此之前仅允许手动输入 |
| D | `not_found/manual_only` | 未找到当前完整方案，或只有旧版、新闻、介绍 | 只允许手动输入，不显示伪造的培养方案课程，也不从相近专业继承 |

B/C 级上传成功后不能直接全局升级来源：升级只对“文件哈希 + 学院 + 专业 + 年级 + 班型/合作项目”完全匹配的解析结果生效。

## 用户身份与 2026 秋名义学期

在使用任何培养方案前，软件必须让用户明确：

1. 学籍所在学院；
2. 专业；
3. 入学年级；
4. 普通班、基地班、珠峰班、菁英班、卓越计划、中外合作等班型；
5. 是否有休学、转专业、留级、提前修读等改变培养进度的情况。

若培养进度正常，2026 年秋季的名义学期映射是：

| 入学年级 | 名义学期 |
|---|---:|
| 2026 | 1 |
| 2025 | 3 |
| 2024 | 5 |
| 2023 | 7 |

这只是默认换算，不是自动选课结论。两份计划都将 `requires_user_confirmation` 设为 `true`；用户必须确认实际学期后才能把建议课程送入排课器。

## 2026 年首次招生专业

学校公告确认以下六个专业于 2026 年首次招生：行星科学、空间科学与技术、机器人工程、人工智能、数字经济、智慧城市与空间规划。截至检索日均未找到可核验的最终逐学期培养方案，因此全部为 D 级，只能手动输入。论证会新闻或专业介绍不能替代最终方案。

## 两份已解析计划的复核边界

课程表页全部以 2.5 倍渲染并逐行视觉核对：

- 测控技术与仪器：PDF 第 19—24 页，68 条记录；
- 自动化：PDF 第 20—25 页，79 条记录。

每条记录至少含 `code`、`name`、`credits`、`recommended_semester`、`category`、`required_or_elective`、`source_page`。源表只给出学分规则而没有具体课程号的“通识选修课程组”和“其他创新创业学分”仍作为规则记录保留，课程号和学期为 `null`，不作猜测。

测控专业源表第 23 页的 `22315100 物联网技术` 存在原文矛盾：总学分为 2，第 7 学期分配栏为 1.5。JSON 原样保留两者，并通过 `measurement-iot-credit-conflict` issue 阻止软件把该行用于自动学分汇总；需教务确认后才能修正。

自动化专业的过程控制系列与运动控制系列是方向二选一，相应 PBL 实践也必须联动选择。相关课程使用 `track_choice` 和 `selection_group`，不能把两套方向同时当作必修。

## 校验

在装有 `jsonschema` 的临时或开发环境运行：

```powershell
python data/curricula/validate.py
```

校验包括：

- 所有 JSON 可解析；
- 两套 Schema Draft 2020-12 校验；
- 97 条来源记录 ID 唯一，且 A/B/C/D 与 `access_mode`、`status` 一致；
- 学校目录 76 个专业完整覆盖；
- 六个 2026 首招专业全部存在且保持 D 级；
- A 类仅有测控技术与仪器、自动化两项；
- 两份计划分别为 68/79 条课程记录；
- 课程页码属于已复核页、课程号不重复、issue 引用有效；
- 学期分配学分与总学分不一致时必须登记 issue。

## 更新原则

1. 只接受学校/学院官网、用户上传的官方原文件或教务系统正式导出。
2. 保留检索日期、URL、发布日期、文件哈希和证据说明。
3. 新文件必须先核对专业、年级、班型，再逐页解析和渲染复核。
4. 不确定内容写入 `issues`，不在数据层“合理推断”。
5. 旧版、新闻、专业介绍、论证材料永远不能自动升级为可导入方案。
