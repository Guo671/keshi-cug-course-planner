课石 · 通用排课助手 0.3.6
由果果开发（Windows 便携版）

完整解压后双击 Keshi.exe。不要只复制 exe；不要在压缩包内直接运行。
支持 Windows 10/11 64位；不用安装Python。原桌面窗口异常时，会自动尝试Edge、Chrome及默认浏览器，使用同一份本地数据。
也可直接双击 Start-in-browser.cmd。成功使用兼容模式后，下次默认沿用；Try-desktop-window.cmd 用于重试原窗口。
浏览器模式下，请保留“课石 · 本机浏览器模式”控制窗口；用完先保存草稿，再点“结束课石”。关闭浏览器本身不会结束服务。换浏览器可能需要重新登录原账号，不用重新注册。
程序不修改Windows安全设置、不解除下载标记、不上传课表。若EXE尚未运行就被智能应用控制阻止，请核对发布来源并反馈Windows提示；不要从陌生站点下载DLL或关闭全部安全保护。
首次启动请等待明确提示（服务最长45秒），不要反复双击。

1. 创建本地账户，填写目标学期和学生信息。
2. 从总库搜索课程、导入 XLS/XLSX，或自行填写课程时间。
3. 设置时间和教师偏好，点击排课。

课程总库管理支持 1–5 个 ZIP 导入、删除和恢复内置库；直接课程导入支持 1–20 个 XLS/XLSX。标准 Excel 模板可以在界面下载。不支持 PDF 或培养方案导入。

升级会保留 %LOCALAPPDATA%\Keshi 下的账号、草稿和历史。旧用户需在“课程总库管理”点击“恢复本版本内置总库”才能使用新版内置数据，也可自行导入新学期总库。

如果同课号下有 A/B 等后缀教学班，请核对理论和实验是否必须一起上，在编辑窗口合并成完整备选组。请假或删课建议不代表学校许可。

实习、课程设计等无具体星期和节次时，按不占时段处理，仍保留在已选课程中。
软件内有离线“使用说明”，其他学校可通过标准Excel模板或手动填课使用。

本版本内置中国地质大学（武汉）2026 秋 1212 门课程、3318 个教学班。数据不是实时选课余量。最终须在教务系统核对并完成选课。

日志：%LOCALAPPDATA%\Keshi\logs\desktop.log
备份：退出课石后复制 %LOCALAPPDATA%\Keshi 文件夹。
